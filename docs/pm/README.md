# Project Management Documentation

This directory contains product management artifacts for AppBoilerplate.

## Documents

| Document | Purpose |
|----------|---------|
| [PRODUCT_VISION.md](./PRODUCT_VISION.md) | Mission, vision, target users, competitive landscape, North Star Metric |
| [ROADMAP.md](./ROADMAP.md) | Quarterly roadmap with RICE-scored features and MoSCoW prioritisation |
| [IMPROVEMENTS.md](./IMPROVEMENTS.md) | Detailed improvement proposals (IMP-001 through IMP-020) with context, expected implementation, and effort estimates |
| [FEATURE_SUCCESS_METRICS.md](./FEATURE_SUCCESS_METRICS.md) | Success metrics for every feature, fork-to-feature funnel, developer satisfaction KPIs |

## Frameworks Used

- **RICE** — Reach × Impact × Confidence / Effort for feature prioritisation
- **MoSCoW** — Must / Should / Could / Won't for quarterly planning
- **North Star Metric** — "Time from fork to first custom feature deployed"
- **Jobs-to-be-Done** — Target user personas defined by the job they hire the boilerplate to do
- **Feature Success Metrics** — Adoption, frequency, depth, retention, satisfaction per feature
- **Funnel Analysis** — Fork → Install → Backend → Simulator → Custom Screen → Deployed

## How to Use

1. **Starting a new quarter?** → Review [ROADMAP.md](./ROADMAP.md) and update priorities
2. **Planning a specific improvement?** → Find it in [IMPROVEMENTS.md](./IMPROVEMENTS.md) by IMP number
3. **Need to measure success?** → Check [FEATURE_SUCCESS_METRICS.md](./FEATURE_SUCCESS_METRICS.md)
4. **Onboarding a new contributor?** → Start with [PRODUCT_VISION.md](./PRODUCT_VISION.md)
